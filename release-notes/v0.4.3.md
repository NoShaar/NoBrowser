## NoBrowser 0.4.3

- Corrige o menu de opções cortado pela webview de páginas web externas (como YouTube).
- O menu de opções agora é exibido como overlay sobreposto à página web com tema e cantos arredondados preservados.
- Corrige o fechamento do menu ao clicar fora (inclusive na página web), ao perder o foco, pressionar Esc ou alternar abas.
